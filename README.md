# Responsive Shopping Website

A multi-page e-commerce front-end built as a personal practice project to apply HTML, CSS, and responsive design principles across a full site structure rather than a single page.

Live Demo: https://fahimeh-masoumi.github.io/shopping-website/

## About

This project simulates a small online store with multiple connected pages, focused on:
- Consistent navigation and layout across pages
- Clean structuring of product, service, and informational content
- Responsive design for mobile, tablet, and desktop screens

## Pages

- `index.html` — Home page
- `about.html` — About the store
- `products.html` — Product listing
- `services.html` — Services offered
- `contact-us.html` — Contact form / info

## Built With

- HTML5
- CSS3
- JavaScript

## Getting Started

Clone the repo and open `index.html` in your browser:

```bash
git clone https://github.com/Fahimeh-Masoumi/shopping-website.git
cd shopping-website
```
